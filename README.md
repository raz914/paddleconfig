# ItemFits AI

A React application with React Three Fiber and Tailwind CSS.

## Setup

Install dependencies:
```bash
yarn install
```

## Development

Start the development server:
```bash
yarn dev
```

## Build

Build for production:
```bash
yarn build
```

## Tech Stack

- React 18
- Vite
- React Three Fiber
- Three.js
- Tailwind CSS
